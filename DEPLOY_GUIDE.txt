=======================================================
   دليل رفع فاتورتك على Hostinger - subfolder
   الرابط: https://unitedcaresd.com/fatortk
=======================================================

الهيكل النهائي على السيرفر:
─────────────────────────────
/domains/unitedcaresd.com/
├── public_html/
│   └── fatortk/              ← محتوى مجلد public فقط
│       ├── index.php          ← المعدل
│       ├── .htaccess          ← المعدل
│       ├── favicon.ico
│       ├── robots.txt
│       └── storage/           ← symlink (يتم إنشاؤه لاحقاً)
│
└── fatortk_app/              ← باقي ملفات المشروع
    ├── app/
    ├── bootstrap/
    ├── config/
    ├── database/
    ├── resources/
    ├── routes/
    ├── storage/
    ├── vendor/
    ├── .env                   ← المعدل
    └── ...

=======================================================
STEP 1: إنشاء قاعدة البيانات
=======================================================
1. سجّل دخول على hPanel
2. اذهب إلى Databases → MySQL Databases
3. أنشئ قاعدة بيانات جديدة
4. احفظ: اسم القاعدة، اسم المستخدم، كلمة المرور

=======================================================
STEP 2: رفع الملفات عبر File Manager
=======================================================
أ) ارفع محتوى مجلد "public" إلى:
   /domains/unitedcaresd.com/public_html/fatortk/

ب) ارفع باقي ملفات المشروع (عدا مجلد public) إلى:
   /domains/unitedcaresd.com/fatortk_app/

ملاحظة: يمكن ضغط الملفات في zip ورفعها ثم فك الضغط

=======================================================
STEP 3: تعديل ملف .env
=======================================================
افتح الملف: /domains/unitedcaresd.com/fatortk_app/.env
وعدّل هذه القيم:

APP_URL=https://unitedcaresd.com/fatortk
DB_DATABASE=اسم_قاعدة_البيانات
DB_USERNAME=اسم_المستخدم
DB_PASSWORD=كلمة_المرور

=======================================================
STEP 4: تشغيل الأوامر عبر SSH Terminal
=======================================================
في hPanel → Advanced → SSH Terminal:

cd /domains/unitedcaresd.com/fatortk_app

# تثبيت المكتبات
composer install --no-dev --optimize-autoloader

# إنشاء symlink للـ storage
php artisan storage:link

# تشغيل migrations
php artisan migrate --force

# مسح وتحسين الـ cache
php artisan config:cache
php artisan route:cache
php artisan view:cache

=======================================================
STEP 5: الصلاحيات
=======================================================
chmod -R 755 /domains/unitedcaresd.com/fatortk_app
chmod -R 775 /domains/unitedcaresd.com/fatortk_app/storage
chmod -R 775 /domains/unitedcaresd.com/fatortk_app/bootstrap/cache

=======================================================
STEP 6: إنشاء symlink للـ storage يدوياً (إذا لم يعمل artisan)
=======================================================
ln -s /domains/unitedcaresd.com/fatortk_app/storage/app/public \
      /domains/unitedcaresd.com/public_html/fatortk/storage

=======================================================
STEP 7: التحقق
=======================================================
افتح: https://unitedcaresd.com/fatortk
- تأكد من ظهور صفحة الهبوط
- جرب تسجيل الدخول
- جرب رفع صورة (شعار الشركة)

=======================================================
في حال وجود مشكلة
=======================================================
- تأكد من PHP 8.2+ في hPanel → PHP Configuration
- تأكد من تفعيل extensions: pdo_mysql, mbstring, openssl, tokenizer
- راجع: /domains/unitedcaresd.com/fatortk_app/storage/logs/laravel.log
