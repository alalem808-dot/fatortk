# فاتورتك — نظام إدارة الأعمال SaaS

نظام محاسبة وإدارة أعمال متكامل مبني على **Laravel 10 / PHP 8.2**، يعمل كـ SaaS متعدد المستأجرين (Multi-Tenant). كل شركة لها بيانات معزولة تماماً عن بقية الشركات.

---

## المتطلبات

| المكوّن | الإصدار |
|---------|---------|
| PHP | 8.2+ |
| MySQL | 8.0+ |
| Composer | 2.x |
| Node.js | 18+ |

---

## التثبيت المحلي

```bash
git clone <repo-url> fatortk
cd fatortk

composer install
npm install && npm run build

cp .env.example .env
php artisan key:generate

# أعدّ بيانات قاعدة البيانات في .env ثم:
php artisan migrate --seed

php artisan storage:link
php artisan serve
```

---

## هيكل النظام

```
فاتورتك
├── Super Admin           → إدارة المنصة والشركات والخطط
└── حساب الشركة (Tenant)
    ├── لوحة التحكم
    ├── المبيعات          → فواتير + عملاء + مرتجعات + مدفوعات
    ├── المشتريات         → أوامر شراء + موردون + مرتجعات + دفعات
    ├── المخزون           → منتجات + مخازن متعددة + جرد دوري
    ├── نقطة البيع (POS)  → كاشير سريع
    ├── البيع السريع      → فواتير مباشرة مع دعم الآجل
    ├── المصروفات         → تشغيلية بفئات مخصصة
    ├── التقارير          → مبيعات + مشتريات + مخزون + P&L
    ├── المستخدمون        → صلاحيات دقيقة + ربط مخازن
    └── الإعدادات         → شعار + عملة + ضريبة + قوالب
```

---

## المكتبات الرئيسية

- **Spatie Laravel Permission** — إدارة الصلاحيات والأدوار
- **DomPDF + mPDF** — تصدير الفواتير بـ PDF
- **Maatwebsite Excel** — تصدير التقارير بـ Excel
